# Zapier Setup Guide — Finora
1. Create a dedicated Google Drive folder named `Finora Campaign Assets`.
2. In Zapier, create a Zap with a trigger supported by your Canva/Drive workflow (for a simple demo, use Google Drive: New File in Folder).
3. Select the campaign asset folder.
4. Add an action: Google Drive — Move File or Copy File (optional, if organizing into subfolders).
5. Add an action: Gmail — Send Email.
6. Map the file name, date and Drive link into the notification.
7. Test using a non-sensitive sample poster.
8. Turn on the Zap only after reviewing permissions and test results.

Note: Available triggers/actions depend on your connected accounts and subscription. This guide does not activate any integration.
