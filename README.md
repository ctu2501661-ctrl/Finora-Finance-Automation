# Finora Financial Solutions — Finance Marketing & Automation Workflow

Prepared by: Armaan Sharma

A student demonstration project inspired by the structure of the referenced Apex Finance workflow. This package uses original Finora branding and synthetic sample data.

## Workflow
Canva campaign design → Zapier trigger → Google Drive file organization → Gmail notification.
Import `Finora_Finance_Sales_Dataset.csv` into Excel or Power BI for analysis.

## Files
- Project report: PDF and editable DOCX
- Presentation: PPTX
- Analytics workbook: XLSX
- Sample dataset: CSV
- Power BI guide and Zapier setup guide

## Important
All company information and records are fictional. No live accounts are connected. Financial promotions require compliance review and appropriate disclosures.
